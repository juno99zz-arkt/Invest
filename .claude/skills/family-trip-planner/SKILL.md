# 가족여행 플래너

가족(특히 아이 동반) 해외여행 일정을 **짜고 → 대안을 비교하고 → 일정표로 정리**하는 작업이다.
여행 계획은 한 번에 끝나지 않는다. 사용자는 날짜, 숙소, 도시 순서, 공항을 바꿔 가며 여러 번 다시 묻는다.
그때마다 전체 일정을 일관되게 다시 계산하는 것이 이 스킬의 핵심이다.

참고 예시: `references/hk-macau-2026.md` (홍콩·마카오 가족여행. 대화에서 실제로 여러 번 바뀐 과정과 최종안)

## 1. 먼저 확정할 입력값

대화에 이미 있는 정보는 다시 묻지 말고 쓴다. 정말 모르는 것만 짧게 묻거나, 합리적인 기본값을 쓰고 "~로 가정했어요"라고 밝힌다.

| 항목 | 왜 중요한가 |
|---|---|
| 날짜(출발일·귀국일, 귀국편이 밤 늦게인지) | 요일·공휴일·박수 계산의 기준 |
| 도시와 도시별 박수 | 숙소 이동 횟수 결정 |
| **입국 공항 / 출국 공항** | 도시 순서를 좌우하는 가장 큰 변수. 추측하지 말 것 |
| 꼭 넣을 일정(디즈니 등) | 요일 배치의 우선순위 |
| 원하는 숙소(특정 호텔) | 동선의 중심점 |
| 동행(아이 나이, 부모님 등) | 하루 이동량과 휴식 배치 |

> 실제 사례: 마카오 → 인천 출국으로 가정해 일정을 짰다가 "마카오 공항이 아니고 홍콩공항"이라고 지적받았다. 출국 공항은 가정하지 말고 확인하거나, 가정했다면 표 위에 분명히 적는다.

## 2. 일정을 짜는 순서

1. **달력부터 계산한다.** 각 날짜의 요일을 직접 계산하고(코드로 확인해도 좋다), 박수 = 귀국일 − 출발일로 맞춘다.
   사용자가 말한 박수와 날짜가 안 맞으면(예: "5박"인데 날짜로는 6박) 먼저 그 차이를 짚는다.
2. **공휴일·이벤트를 확인한다.** 현지 공휴일, 크리스마스·춘절 같은 연휴, 테마파크 시즌 이벤트, 운영 휴무일.
   가능하면 웹 검색으로 그 해 정보를 확인하고 출처를 남긴다.
3. **테마파크는 평일에 둔다.** 주말·공휴일·연휴를 피하고, 도착 다음 날 이후 체력이 좋은 초반에 배치한다.
   테마파크 다음 날은 가벼운 일정으로 둔다.
4. **도시 순서는 공항으로 정한다.** 입국 공항 근처 도시를 먼저, 출국 공항 도시를 마지막에 두면 마지막 날 이동이 가장 짧다.
   예: 홍콩 IN/OUT이면 홍콩공항 → 강주아오대교로 바로 마카오 → 홍콩 순서가 유리하다.
5. **숙소 이동을 최소화한다.** 아이 동반이면 짐 옮기는 횟수가 체감 피로를 좌우한다. 한 숙소 연박을 우선 검토한다.
6. **마지막 날을 설계한다.** 심야편이면 레이트 체크아웃, 짐 보관, 시내(인타운) 체크인, 공항까지 소요시간을 역산한다.
7. **하루 동선은 지역별로 묶는다.** 같은 날 섬·지역을 오가지 않게 하고, 실내 대안(비 오는 날)을 하나씩 둔다.

## 3. "이건 어때?" 질문에 답하는 방식

사용자가 대안을 물으면 결론부터 말하고 비교한다.

- 첫 문장에 판단을 쓴다. ("좋은 선택이에요", "이 경우엔 순서를 바꾸는 게 나아요")
- 바뀐 조건으로 **일자별 표 전체를 다시** 보여 준다. 부분만 고치면 박수·요일이 어긋나기 쉽다.
- **좋아지는 점 / 주의할 점**을 나눠 쓴다.
- 대안이 2개 이상이면 비교표(안 / 구성 / 장점 / 단점)를 쓰고 추천안을 하나 고른다.
- 결정이 필요하면 마지막 줄에 무엇을 정해야 하는지 한 줄로 묻는다.

## 4. 결과물 형식

### 일자별 표 (채팅·문서 공통)

| 날짜 | 일정 | 숙박 |
|---|---|---|
| 12/12(토) | 도착 → … | 호텔명 |

- 날짜에는 항상 요일을 붙인다.
- 테마파크 날은 🏰 같은 표시와 굵은 글씨로 눈에 띄게 한다.
- 시간 단위 상세 일정은 문서나 웹페이지에 넣고, 채팅에서는 하루 한 줄로 요약한다.

### 문서로 정리할 때

일정이 확정되면 두 가지를 만든다.

1. **마크다운 문서** (`travel/<도시>-<연월>.md`). 구성:
   - 한눈에 보기 표
   - 준비 체크리스트
   - 일자별 시간표
   - 교통 정리
   - 맛집
   - 레퍼런스 링크(공식 사이트, 참고 기사, 사진 갤러리 링크)
   - 가족여행 팁
2. **공유용 일정표 웹페이지**. `assets/itinerary-template.html`을 출발점으로 쓴다.
   도시별 색 구분, 날짜 칩 바로가기, 일자별 카드, 예약 순서·준비물·공식 사이트 박스로 되어 있다.
   날짜, 도시, 숙소, 색 토큰만 바꿔서 재사용한다.
   Artifact로 게시하면 가족에게 공유할 수 있다. 게시 직후에는 비공개 상태이므로 공유 메뉴에서 공유해야 한다고 알린다.

### "메신저용"이라고 하면

한 줄에 공백 포함 26자 이내로 줄여서 쓴다.

```
[홍콩·마카오 12/12~19]
12/12 토 도착→마카오 이동
12/13 일 마카오 구시가지
12/14 월 타이파→홍콩 하얏트
12/15 화 🏰디즈니랜드
```

## 5. 정확성 원칙

- 운영시간, 요금, 페리 노선, 호텔 위치처럼 확인하지 못한 정보는 "예약 전 공식 사이트 확인"으로 표시한다. 확인한 척하지 않는다.
- 웹 검색으로 확인한 정보는 출처 링크를 남긴다.
- 사진을 직접 넣을 수 없으면(네트워크 차단 등) 명소별 갤러리 링크와 해시태그로 대신하고, 그렇게 했다고 밝힌다.
- 일정이 바뀌면 이전 표의 날짜·요일·박수를 다시 계산한다. 이전 답의 표를 복사해 일부만 고치지 않는다.
