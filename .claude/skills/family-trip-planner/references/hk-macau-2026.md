# 참고 사례: 홍콩·마카오 가족여행 (2026년 12월)

실제 대화에서 일정이 어떻게 바뀌었는지와 최종 검토안. 비슷한 요청이 오면 이 흐름을 참고한다.

## 일정이 바뀐 과정

| 단계 | 사용자 요청 | 판단 |
|---|---|---|
| 1 | 12/20~22 마카오, 12/22~26 홍콩, 디즈니 포함 | 크리스마스 연휴(12/24~26)를 피해 디즈니를 12/23(수)로 배치 |
| 2 | 마카오 호텔 없이 하얏트 리젠시 침사추이 5박? | 날짜상 6박이라 1박이 남는다고 먼저 짚음 → 디즈니 호텔 1박 + 하얏트 5박 제안 |
| 3 | 전부 하얏트로? 마카오가 부족하지 않을까? | 마카오 하루치기 가능 범위 vs 아쉬운 점 비교, A/B/C안 비교표 |
| 4 | 홍콩 먼저, 마카오 나중? | 장점(체력 배분, 편한 마무리) + 주의(12/25 페리 혼잡) |
| 5 | 12/12~19 밤 늦게, 홍콩 5박 + 마카오 2박 | 연휴 1주 전이라 덜 붐비고 저렴, 디즈니 크리스마스 행사 기간 |
| 6 | **"마카오 공항이 아니고 홍콩공항"** | 출국 공항을 잘못 가정했음 → 마카오 먼저, 홍콩 나중으로 순서 변경 |

교훈: 출국 공항과 박수를 처음에 확정했다면 2·6단계의 수정이 필요 없었다.

## 최종 검토안 (12/12 토 ~ 12/19 토 심야, 인천↔홍콩공항 왕복)

| 날짜 | 일정 | 숙박 |
|---|---|---|
| 12/12(토) | 홍콩공항 도착 → 강주아오대교 버스(약 40분)로 바로 마카오 → 코타이 | 마카오 |
| 12/13(일) | 세나도 광장 · 성바울 성당 유적 · 아마 사원 · 마카오 타워 → 야경 | 마카오 |
| 12/14(월) | 타이파 · 콜로안 에그타르트 → 버스나 페리로 침사추이 | 하얏트 리젠시 침사추이 |
| 12/15(화) | 🏰 **디즈니랜드 종일** (평일) | 하얏트 |

| 12/17(목) | 빅토리아 피크 · 센트럴 · 스타페리 | 하얏트 |

## 지역 메모

- **홍콩 디즈니랜드**: 크리스마스 행사 「A Disney Christmas」 2026.11.20 ~ 2027.1.3. 월드 오브 프로즌(프로즌 에버 애프터)을 개장 직후 1순위로. 저녁 캐슬 쇼 「Momentous」. 침사추이에서 지하철 40~50분.
- **마카오 ↔ 홍콩**: 강주아오대교 셔틀버스(24시간, 약 40분 + 출입국)는 홍콩공항과 가까움. 침사추이에서는 페리(약 1시간)가 편함.
- **마카오에서 홍콩공항으로 출국할 경우**: 버스 + 택시(1.5~2시간), 공항 직행 페리(운항 확인 필요), 국경 통과 전용 차량(비쌈). 출발 5시간 전 코타이 출발.
- **공휴일**: 마카오 12/20 반환기념일, 홍콩 12/25~26. 연휴에는 홍콩 사람들의 마카오 방문으로 페리가 혼잡.
- **시내 체크인**: 홍콩역·구룡역에서 가능하지만 항공사별로 다름.
- **12월 날씨**: 15~21℃, 건조. 레이어드 복장.
