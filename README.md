# Invest · 미국 주식 장기 리서치

미국 주식, 6개월 이상 보유를 위한 개인 리서치 도구입니다. 기존 저장소의 고정 대형주 후보군 50개를 수집하여 주간 후보 최대 3개와 정량 심층보고서를 생성합니다. 전체 미국 시장 스크리너나 검증된 수익률 예측 모델은 아닙니다.

## 실행

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python generate_invest.py
python -m http.server 8000 --directory dist
```

브라우저에서 http://localhost:8000 을 엽니다. `index.html`은 데이터가 없는 소스 템플릿이며, 실제 배포 파일은 `dist/index.html`입니다. 생성기는 템플릿을 덮어쓰지 않습니다.

이전 기록을 유지하려면 다음처럼 실행합니다.

```sh
python generate_invest.py --previous dist/research.json
```

`--tickers AAPL,MSFT,NVDA`는 제한된 후보군으로 수집을 확인하는 옵션입니다. 해당 결과를 전체 50개 추천 결과로 배포하지 마세요.

## 데이터 신뢰성 수정

기존 생성기는 `mock_data.py`에서 추천·뉴스·내부자 거래를 가져와 일부 가격과 오늘 날짜만 갱신했습니다. 새 생성기는 mock 모듈을 import하지 않으며 실패 시 예시 값으로 대체하지 않습니다. 기존 `mock_data.py`와 이전 수집 함수는 참고를 위해 소스에 보존하지만 배포에는 포함하지 않습니다.

- 수집 시점 2일, 가격 시점 5일, 공급자 최근 분기말 150일 이내인지 확인합니다. 미래 날짜도 제외합니다.
- 12개 필수 지표가 없으면 해당 종목의 추천을 보류합니다. NaN/무한대를 유효 수치로 취급하지 않습니다.
- 금융·부동산은 일반기업 현금흐름 모형을 그대로 적용하지 않고 보류합니다. 후보군은 미국 상장 주식이며 미국 외 소재 기업의 미국 상장 주식도 포함합니다.
- 후보군 80% 이상이 날짜 검증을 통과해야 새 주간 목록을 생성합니다. 장애 시 이전 기록은 유지하고 최신 수집 상태는 불완전으로 표시합니다.
- 회사 소개와 기사 제목은 Yahoo Finance 공급자 콘텐츠입니다. 뉴스는 최근 14일 제목·출처·날짜·링크만 수집하며 점수에 반영하지 않습니다.
- 공급자 최근 분기말은 공시일이 아니며 모든 재무 지표가 같은 기간이라는 보장은 없습니다. 원문 검증 완료로 표시하지 않습니다.

## 선정 규칙 v1

| 신호 | 만점 | 규칙 |
|---|---:|---|
| 매출 성장 | 25 | YoY 15% 이상 25 / 8% 이상 18 / 양수 10 |
| 영업이익률 | 20 | 20% 이상 20 / 10% 이상 14 / 양수 6 |
| FCF 수익률 | 20 | FCF÷시가총액 5% 이상 20 / 3% 이상 14 / 양수 7 |
| 재무 여력 | 15 | 순부채÷EBITDA 0 이하 15 / 1 이하 11 / 3 이하 6 |
| 상대 가격 | 10 | 동일 섹터 중앙값 대비 선행 PER 0.85 이하 10 / 1.1 이하 7 / 1.4 이하 3 |
| 이익 전망 변화 | 10 | 현재 회계연도 예상 EPS의 30일 변화 3% 이상 10 / 0% 이상 6 |

65점 이상, 양의 매출 성장·영업이익률·FCF 및 이익, 순부채/EBITDA 3배 이하를 요구합니다. 동일 섹터 최대 2개이며 점수 동률은 티커순입니다. 비교 섹터 3개 미만 또는 EPS 수정 이력 미확보 시 해당 가점은 0입니다. 이 가중치와 임계치는 초기 휴리스틱이며 백테스트나 개인별 위험 적합성을 검증하지 않았습니다.

매주 ISO 주차(KST)의 첫 정상 실행에 목록을 고정합니다. 이후 매일 최신 정량 분석을 갱신하지만 선정 당시 수치와 이유는 변경하지 않습니다. 다음 주에는 신규·유지·제외와 이유를 기록합니다. 추천 후보 부족은 빈 목록/1~2개로 명시합니다.

## 보고서와 한계

보고서는 수치 기반 투자 근거, 반대 근거, 6~12개월 확인 과제, 신호별 점수, 기사 링크, 사업 소개 및 가격 민감도를 제공합니다. 민감도는 선행 EPS와 현재 가격에 내재된 PER을 사용하며 목표가·예측·확률이 아닙니다. 하락(EPS -20%, PER -20%), 유지(변화 없음), 상승(EPS +15%, PER +10%)은 설명용 가정입니다.

공시/기사 본문을 읽는 LLM 분석, 경제적 해자 검증, 실적발표 일정 확인, 보유비중 최적화 및 자동매매는 구현하지 않았습니다. API 키가 없는 상태에서 AI가 읽었다고 꾸미거나 촉매를 만들어내지 않습니다. 추천 기록의 가격 변화는 배당·분할·환율·비용을 보정하지 않아 투자성과 지표가 아닙니다.

## GitHub Actions와 배포

- `update_invest.yml`: 매일 17:00 KST 또는 수동 실행. 실제 시작 시각은 Actions 스케줄 지연의 영향을 받습니다.
- 기존 `gh-pages`의 `research.json`을 먼저 복원하고, 테스트와 생성 후 `dist/`만 배포합니다. 과거 브리핑이 처음 마이그레이션되어 기록 파일이 없는 경우 새 기록으로 시작합니다.
- `gh-pages` 접근 실패는 기록 유실을 막기 위해 작업을 실패시킵니다.
- 배포는 main 실행에서만 수행합니다. 브랜치 실행은 검토용 artifact만 생성합니다.
- 화면의 '수집 실행'은 Actions 페이지를 엽니다. 로그인 후 Run workflow를 실행하고 작업 완료 후 화면을 새로고침해야 합니다. 브라우저에 토큰을 저장하지 않습니다.
- GitHub Pages의 게시 소스는 기존 `gh-pages` 브랜치를 유지합니다. 병합만으로 즉시 배포되지 않으며 다음 예약/수동 실행이 필요합니다.
